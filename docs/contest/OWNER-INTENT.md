# The owner's intent (verbatim where quoted, 2026-10-02)

The owner shortlisted two entries from ten researched concepts: Habit Garden as the **realistic** aim and a VR
spell-duel as the experimental one (designed elsewhere; not part of this contest).

> "Habit garden as realistic hackathon aim - it aims to be practical, some can be executed within the app like guided breathing meditation."

> "...three competing design approaches for the Habit garden - scope of features, customer journey experience, art direction, techstack. With design in mind large part should be testable on Windows machine with any supporting dev tools Meta has. The app excellence needs to be designed first, if there are emulators or toolkits helping it would help."

The seed pitch the owner reacted to (host's earlier words, not a spec):
> A tiny living garden that grows from your real daily habits - water a plant with a gesture when you complete one.
> Glanceable micro-moments on the glasses; the full garden on Quest. Few entries will be designed glasses-first.

Who builds it: the owner (an experienced TypeScript / React / Rust developer, new to shipping VR) working with
autonomous coding agents (Claude Code, Codex) that can run anything scriptable on Windows 11 but cannot wear a
headset. The owner's time in a headset is the scarcest resource; anything an agent can verify on Windows, it should.
The same owner is building a second, harder VR entry in parallel, so this one must be achievable.
