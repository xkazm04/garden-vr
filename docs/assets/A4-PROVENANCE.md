PLAN A4: every texture has a provenance sidecar. Each .png under apps/*/Assets/Art/Textures/ has exactly one status:

- **sidecar**: a tracked `<name>.png.provenance.txt` beside it (declared origin: its `method` field).
- **row**: no sidecar, but a row of that folder's `PROVENANCE.md` table whose first cell, backticks stripped, equals the file name exactly (declared origin: the second cell). A name that is a prefix of another row's name does not count; a brace row such as `plant_{a,b}.png` names no single file and does not count.
- **missing**: neither.

Declared-derived counts the textures whose sidecar says `derived_from_art_reference: yes` or whose row says it is derived from the art reference.

**This census reads declarations, not pixels. It cannot prove that no pixel is borrowed from the art reference; it proves only that every texture names an origin, and which origins say they were derived.**
